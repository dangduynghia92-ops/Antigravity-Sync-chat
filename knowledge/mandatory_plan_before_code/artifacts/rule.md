# MANDATORY: Plan Before Code

## Rule
NEVER write or modify source code until:
1. A plan/proposal has been presented to the user
2. The user has EXPLICITLY approved the plan

## What counts as approval
- User says "ok", "làm đi", "triển khai", "đồng ý", or similar
- User picks a specific option from proposed alternatives

## What does NOT count as approval
- User describes a feature or requirement → this is a QUESTION, not an order
- User asks "có làm được không?" → this is asking for feasibility, NOT asking to implement
- User says "ok" to an explanation → this confirms understanding, NOT approval to code

## Workflow
1. User describes requirement
2. I present plan with options (WHERE to add, HOW it works, WHAT changes)
3. User reviews and approves specific option
4. ONLY THEN I write code

## Violations
- Starting to edit files before plan approval
- Researching code structure AND editing in the same turn
- Assuming "ok" to an explanation means "implement it"
